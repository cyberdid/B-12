# H. Голос і персона — нотатки

Джерело: `hermes-agent` @ `514e2cbd`: `user-guide/features/voice-mode.md` (How it works, Silence detection, stop by voice, streaming STT/TTS, client-direct, GPT-Live, voice chat model, barge-in, hallucination filter), заголовки `wake-word.md`, `tts.md`; `personality.md`, `pets.md` (вступ). Наш бік: `src/b12/audio/` (3005 рядків: `aec.py`, `endpoint.py`, `duplex.py`, `live.py`, `pipeline.py`, `tts.py`, `speaker.py`), `persona.py`.

## Hermes (док)
- **Цикл голосу в CLI:** PTT (Ctrl+B) → запис → 3 с тиші → Whisper → агент → TTS → запис знову; після трьох «порожніх» записів поспіль режим виходить.
- **Кінець репліки:** RMS-поріг 200 ≥0,3 с, кінець після 3,0 с тиші; без мови 15 с → стоп. Це простіше за наш Silero VAD.
- **Стоп-фраза:** «stop» розпізнається лише як **уся репліка** (строгий збіг), тож «stop doing that and…» доходить до агента.
- **Потоковий STT** (OpenAI/xAI/ElevenLabs) — у разі збою переходить на файл, «жоден запис не губиться».
- **Потоковий TTS:** буфер до цілого речення (≥20 символів), очищення markdown/емодзі/`<think>`, відтворення по реченнях; PCM-стрімінг у провайдерів, що його підтримують.
- **Barge-in:** повний дуплекс; поріг відносно «тихої кімнати», каліброваної на початку ходу (а не під час відтворення); множник 3,0; пауза 0,5 с після початку відтворення. Перебивання під час «думання» скасовує хід; під час мовлення — обриває мовлення.
- **Модель знає, що її перебили:** наступне повідомлення несе коротку примітку «твою відповідь обірвали», щоб вона могла природно відреагувати або продовжити.
- **Окрема «голосова» модель:** швидша модель для голосових ходів; reasoning вимкнено за замовчуванням; той самий набір інструментів; наступний текстовий хід — знову основна модель.
- **Фільтр галюцинацій Whisper:** 26 відомих фантомних фраз кількома мовами («Thank you for watching», «Subscribe»…) + регулярний вираз на повтори.
- **Wake word:** sherpa (будь-яка фраза без навчання), openWakeWord (навчена модель), Porcupine; є розділ про хибні спрацювання на фонову мову.
- **GPT-Live:** повнодуплексна хмарна голосова модель без інструментів, яка делегує «справжню роботу» агенту — не local-first, для B-12 не підходить.
- **Персона:** `SOUL.md` у домашній теці — редагований файл ідентичності, слот №1 промпту, сканується на ін'єкції; пресети `/personality` — накладки на сесію. Чітке розділення: SOUL = голос і характер, AGENTS.md = правила проєкту.
- **Pets:** анімований маскот із 6 станами (`failed`, `jump`, `wave`, `run`, `review`), що віддзеркалює стан агента; чисто візуально.

## B-12 (звірено з кодом)
- Повний дуплекс «без чергування слухати/говорити» (`live.py`): кадри по 32 мс → AEC (системний WebRTC через PipeWire + NLMS FIR, детектор подвійної мови, «echo dominant», забруднення медіа) → barge-in з **SpeakerID** (scoped barge-in: перебиває лише розпізнаний мовець) → сегментатор → ASR один раз → хід агента як задача.
- Silero VAD (ONNX) і детектор кінця репліки; потоковий TTS по клаузах (`extract_stream_clauses`), нормалізація чисел для української, мовна детекція речень (uk/en), earcon.
- `is_tts_echo_text` — відкидає транскрипт, що збігається з тим, що щойно сказав сам B-12.
- Немає: фільтра фантомних фраз Whisper, wake word, строгої стоп-фрази, примітки моделі «тебе перебили», окремої швидкої моделі для голосу.
- Персона жорстко прописана в коді (`CAPRI_PERSONA_PROMPT`) + профіль компаньйона.

## Порівняння (чесно)

|---|---|---|
| AEC / відлуння | — (калібрування порогу) | **так**: WebRTC AEC + NLMS, подвійна мова, відкидання власного ехо-транскрипту |

| VAD | RMS-поріг | **так**: Silero VAD |
| Фантомний текст ASR | **так**: список фраз + повтори | немає (є лише ехо-фільтр) |

| Редагована персона | **так** (SOUL.md) | у коді |
| Українська | загальні провайдери | **так**: нормалізація чисел, uk/en по реченнях |

## Кандидати на перенесення (дешеві й корисні)
1. **Примітка «тебе перебили»** в наступному ході після barge-in (наприклад «[твою попередню відповідь перервано на: «…»]»), як дані, не як інструкція. Дешево; покращує природність.
2. **Фільтр фантомних фраз ASR** з українськими фантомами Whisper («Дякую за перегляд», «Субтитри зроблені…», «Продовження далі», повтори). Зібрати список з наших записів тиші/шуму (без збереження аудіо гостей).
3. **Строга стоп-фраза** («стоп», «замовкни», «досить») — лише ціла репліка → скасувати хід і мовлення через контрольний шлях (не модель).
4. **Wake word** — openWakeWord/sherpa локально; окремий ADR (приватність: детектор працює на пристрої, до активації нічого не пишеться).
5. **SOUL.md-подібний файл персони** власника поверх базової персони Capri, сканований і обмежений; лише голос і стиль, ніяких дозволів.
6. **Стан-маскот** — для Capri вже є фізичне тіло; ідея «6 станів агента → анімація/LED» може лягти на роботизовану частину (`src/b12/robotics`).
