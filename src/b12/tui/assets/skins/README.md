# Зовнішні скіни companion

Кіберкіт вбудований і вибирається при кожному запуску. Опційний локальний pack можна
підключити через `B12_TUI_CAPRI_DIR`, після чого перемикати персонажа через F9 у TUI.
Вибір не змінює B-12 runtime, особистість моделі, пам'ять чи дозволи.

Capri artwork не входить до репозиторію. Використовуй власні або дозволені автором
файли та запиши їх походження в manifest. Завантажувач перевіряє наявність metadata,
але не підтверджує право використання і не відкриває URL із `provenance`.

Приклад розташування поза Git:

```text
~/.local/share/b12/skins/capri/
  manifest.json
  atlas.png
```

```bash
B12_TUI_CAPRI_DIR="$HOME/.local/share/b12/skins/capri" uv run --no-sync b12 tui
```

Змінна може вказувати на `manifest.json`, на каталог одного pack або на каталог із
підкаталогами pack. У третьому випадку переглядаються максимум 32 записи каталогу;
для передбачуваного вибору краще вказувати безпосередньо каталог потрібного pack.
Некоректні pack пропускаються. Невдала зміна скіна повертає кіберкота.

## Manifest v1

```json
{
  "version": 1,
  "id": "capri",
  "display_name": "CAPRI",
  "atlas": "atlas.png",
  "frame_width": 256,
  "frame_height": 256,
  "columns": 4,
  "rows": 2,
  "frame_duration_ms": 240,
  "phases": {
    "idle": [0, 1],
    "thinking": [2, 3],
    "speaking": [4, 5],
    "success": [6],
    "purr": [7]
  },
  "provenance": {
    "source": "https://example.org/your-authorized-artwork",
    "license": "LicenseRef-owner-permission",
    "attribution": "Автор і дата дозволу на використання"
  }
}
```

Це опис формату; приклад не містить зображення або дозволу на оригінальний Capri.

| Поле | Правило |
|---|---|
| `version` | Ціле число `1`. |
| `id` | 1–48 символів: мала ASCII-літера, далі малі літери, цифри, `_` або `-`; `cybercat` зарезервовано. |
| `display_name` | Непорожня назва до 64 друкованих символів, без `[` і `]`. |
| `atlas` | Відносний шлях усередині pack; абсолютні шляхи, `..`, Windows drive paths та symlink за межі pack відкидаються. |
| `frame_width`, `frame_height` | Цілі числа 1–512. Прямокутні кадри зберігають свої фізичні пропорції в terminal cells. |
| `columns`, `rows` | Цілі числа 1–32; максимум 256 клітинок. Кадри нумеруються від нуля зліва направо, зверху вниз. |
| `frame_duration_ms` | 120–5000 мс; UI оновлює анімацію кожні 120 мс. F8 зупиняє її на першому кадрі поточної фази. |
| `phases` | Обов'язковий `idle`; кожне значення — 1–256 номерів кадрів із цього atlas. Відсутня фаза використовує `idle`. |
| `provenance` | Непорожні `source`, `license`, `attribution`, кожне до 1024 друкованих символів, без `[` і `]`. |

Фази: `idle`, `typing`, `thinking`, `speaking`, `working`, `approval`, `success`,
`error`, `cancelled`. Опційні локальні реакції: `purr`, `look_left`, `look_right`,
`look_up`, `look_down`. Погладжування має пріоритет; напрямок погляду застосовується
у фазах `idle` та `typing`. Для інших фаз діє їхня анімація або `idle`.

Atlas має бути справжнім RGBA PNG із розмірами точно
`frame_width × columns` на `frame_height × rows`: максимум 4096 пікселів на бік,
16 777 216 пікселів і 32 MiB у файлі. Manifest обмежений 64 KiB. Усі клітинки
компонуються на спільне тло TUI; файли pack не переписуються. Кеш кадрів і кеш
terminal renderables мають межу 48 кожен. Під час зміни скіна або розміру renderer
звільняє лише власні terminal images.

Завантажувач не виконує код із pack, не завантажує мережеві ресурси й не записує
asset-файли. Неправильна схема, пошкоджений PNG або відсутній atlas не завершують
TUI; для інтерфейсу повертаються `skin_pack_invalid` або `skin_unavailable`.
