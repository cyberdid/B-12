\subsection{Scoring and artifact reconstruction}
The current scorer implements explicit text inclusion/exclusion, script checks, character limits, turn states, selected tool names, file existence/equality, memory conditions and unchanged-control checks. These are executable operational definitions, not a learned judge of every answer. Current scorer source is not substituted for the historical corpus: historical metadata supplies case hashes, while the saved result rows supply recorded pass fields. This revision independently aggregates those fields by context and category and checks them against the stored summary. It does not re-score the original semantic judgments.

The sanitized supplementary outcome file retains only case ID, category, repetition, context, multi-step flag and pass status. It allows readers to recompute the reported arithmetic without publishing transcripts. It does not allow verification of every underlying file effect or check decision; those require the original locally stored traces. This distinction separates arithmetic reproducibility from independent experimental reproduction. Hardware power state, cache residency and the completeness of historical environment control remain limitations.
